# Architecture Overview

- **Hexagonal** services with ports/adapters.
- **Event‑driven** domain with **CQRS** and **Event Sourcing**.
- **MACH**: Microservices, API‑first, Cloud‑native, Headless portal.
- **Security**: zero‑trust, SPIFFE, OIDC/SAML/SCIM, API keys.
- **Observability**: OTel traces/metrics/logs; RED/USE dashboards.
- **Resilience**: mesh timeouts/retries/bulkheads, rate limits, KEDA autoscale.
