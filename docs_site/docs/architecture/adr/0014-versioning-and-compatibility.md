# ADR 0014: Versioning & Compatibility

- **Status**: Accepted
- **Date**: 2025-11-13
- **Decision**: SemVer for packages; add‑only for GraphQL; deprecations with 90‑day window; tolerant readers for events; Protobuf `reserved`.
- **Why**: Predictable evolution.
- **Consequences**: Requires release notes and deprecation tracking.
