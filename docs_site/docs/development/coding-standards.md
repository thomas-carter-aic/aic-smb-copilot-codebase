# Coding Standards

## Go
- `gofumpt`, `golangci-lint`, table‑driven tests, context‑first APIs.
## TypeScript
- `eslint` + `prettier`; prefer async/await; typed APIs via generated clients.
## Python
- `ruff` + `black` + `mypy`; FastAPI for services.
## Java
- JDK 21; Gradle; Spotless; JUnit5.
## Contracts
- Avoid breaking changes; use `reserved` in Protobuf; additive evolution.
