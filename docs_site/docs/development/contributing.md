# Contributing

- **Branching**: trunk‑based; short‑lived branches.
- **Commits**: Conventional Commits (`feat:`, `fix:`, `chore:`).
- **PR template** includes risk, test plan, SLO impact.
- **CI** runs lint/tests, contracts validation, secret & vuln scans.
- **Pre‑commit**: install with `pre-commit install --config dev/.pre-commit-config.yaml`.
